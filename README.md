### 🔧 IssueFlow

Java | Spring Boot 3 | PostgreSQL | JWT

A REST API backend for issue tracking, built to explore concurrency-safe data design and real-world backend architecture concerns.

**Key Features:**
- Optimistic locking (`@Version`) for safe concurrent updates
- BFS-based cycle detection for issue dependency graphs
- Stateless JWT authentication with a token deny-list for logout
- Status state machine and least-loaded auto-assignment
- Scheduled service for automatic overdue-issue escalation
- CSV import with per-row error handling

🔗 Repository: [issueflow-java](https://github.com/liram-hen/issueflow-java)
